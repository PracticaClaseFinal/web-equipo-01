FLORAL ROYAL - PÁGINA WEB
=========================

Contenido de la carpeta:
- index.html      -> página principal
- styles.css      -> diseño visual y versión adaptable a celular
- script.js       -> carrito/pedido y botón de WhatsApp
- assets/         -> logo, marca, eslogan e imágenes de productos

CÓMO EJECUTARLA
1. Descomprime la carpeta si recibiste un ZIP.
2. Abre la carpeta "floral_royal_web".
3. Haz doble clic en "index.html".
4. Se abrirá en Chrome, Edge, Firefox u otro navegador.

CONFIGURACIÓN OBLIGATORIA DE WHATSAPP
1. Abre "script.js" con Bloc de notas o Visual Studio Code.
2. Busca:
   whatsappNumber: "521XXXXXXXXXX"
3. Sustituye el valor por tu número de WhatsApp en formato internacional,
   SIN +, espacios ni guiones.
   Ejemplo México: 5219991234567

PRECIOS
La información original no proporcionó precios. Por eso la web muestra
"Precio a consultar". Cuando tengas los precios puedes modificar cada tarjeta
en index.html o pedirme que te entregue una segunda versión con precios,
carrito con total y pago en línea.

PUBLICAR EN INTERNET
Para publicarla de forma gratuita puedes usar GitHub Pages, Netlify o Vercel.
Para un negocio formal conviene usar dominio propio y, si deseas cobrar en
línea, integrar una pasarela de pago con un backend seguro.
